# Meridian VPN для Linux

Проект находится в разработке. Готового Linux-клиента и установщика пока нет; не используйте этот репозиторий как рабочий VPN.

В репозитории размещены общие компоненты desktop-клиента и движок Meridian. Linux-интеграция, системная служба, интерфейс и проверка защиты трафика ещё не завершены.

## Происхождение

- Desktop core: `JinComputers/meridian-desktop`, commit `af67c6b47928c452cfefb902e70d5cbfbf0f5223`.
- Engine: `JinComputers/meridian-android-src`, commit `8bd702c9083ca0bdc0769897a00129d30f43b5a1`; включён в `engine/` для воспроизводимой сборки.

## Проверка общих компонентов

Требуется Go 1.27.1. `go test ./core/...` проверяет общую логику; `GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build ./core/...` проверяет её компиляцию для Linux. Эти команды не собирают и не проверяют VPN-клиент.

Не размещайте в репозитории ключи абонентов, токены, сертификаты и журналы с секретами.
