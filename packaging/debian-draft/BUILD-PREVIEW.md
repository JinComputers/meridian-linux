# Сборка preview для Debian 12 amd64

Это предварительный пакет для проверки владельцем, не публичный релиз. Он
включает полный туннель и прежние ограничения экспериментальной службы. Не
используйте пакет как подтверждение готовности к выпуску.

Собирать на отдельной системе Debian 12 amd64. Требуются Git, `dpkg-dev`,
`debhelper`, `gcc`, `pkg-config`, `libgtk-3-dev`, `libwebkit2gtk-4.1-dev` и
**Go 1.27.1**, установленный отдельно: системный Go Debian 12 старее. Укажите
именно этот Go первым в PATH. Исходники engine находятся в `engine/`; модули Go
и суммы версий закреплены в обоих `go.mod`/`go.sum`. Подготовьте кэш зависимостей
заранее, если сеть недоступна.

Из чистого, закоммиченного checkout выполнить:

```sh
./scripts/build-deb-preview.sh
```

Скрипт создаёт временную копию **только из Git HEAD** и выводит пакет и SHA-256
в `build/deb-preview/`. Он останавливается при незакоммиченных изменениях
отслеживаемых файлов. GUI и служба собираются из одного снимка; в
`/usr/share/doc/meridian-vpn/build-info.txt` пакета записаны commit, время
commit, версии компилятора и библиотек, SHA-256 бинарников. Служба не запускается
при установке, но при настройке пользователем разрешает экспериментальную сеть.

Для повторяемого результата используйте те же версии Debian-пакетов, Go и их
исходники; версии C-компилятора и библиотек фиксируются в build-info. Полная
битовая воспроизводимость и вся матрица систем ещё должны быть проверены на
изолированном x86_64; скрипт намеренно отказывает на другой архитектуре.
